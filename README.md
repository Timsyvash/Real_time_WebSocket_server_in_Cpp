# Real-time WebSocket Server in C++ (ESP8266 + WebSockets + RGB LED Control)

Цей проєкт демонструє створення високопродуктивного, неблокуючого **WebSocket-сервера реального часу** на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Система забезпечує двосторонній зв'язок із мінімальними затримками між мікроконтролером та веббраузером, дозволяючи керувати кольором RGB-світлодіода "на льоту" без перезавантаження сторінки.

---

## 🚀 Основні можливості

* **Двосторонній зв'язок у реальному часі (Bi-directional Streaming)**: Використання протоколу WebSockets для миттєвої передачі команд від клієнта до сервера та від сервера до клієнта.
* **Неблокувальна архітектура (Finite State Machine - FSM)**: Розподіл логіки на стани (`SETUP_WIFI`, `RUNNING`) за допомогою `millis()`, що повністю виключає зависання та спрацьовування сторожового таймера (Watchdog Reset).
* **Вбудована вебпанель управління**: Сервер генерує інтерактивний HTML/JS інтерфейс із повзунками (sliders) для плавного змішування кольорів RGB без потреби у зовнішній файловій системі.
* **Підтримка mDNS**: Доступ до пристрою в локальній мережі за зручною адресою `http://esp8266.local` замість запам'ятовування IP-адреси.
* **Моніторинг з'єднань**: Автоматичний підрахунок та пінгування активних WebSocket-клієнтів у реальному часі через Serial Monitor.

---

## 🛠 Апаратне забезпечення та підключення

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Виконавчий пристрій**: RGB-світлодіод із загальним катодом/анодом, підключений до таких пінів:
  * **Червоний (LED_RED)**: GPIO 15 (D8)
  * **Зелений (LED_GREEN)**: GPIO 12 (D6)
  * **Синій (LED_BLUE)**: GPIO 13 (D7)
